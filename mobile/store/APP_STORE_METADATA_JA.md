## Description
KoiRelaは、恋愛の悩みを誰かに話したいときに使える、1対1のリアルタイムチャット相談サービスです。

相談員のプロフィールや得意な相談内容を見て、自分で話したい相手を選べます。

主な機能
- 15分100円のリアルタイム相談
- 経験者・資格者から相談相手を検索
- 名前、相談内容、相談員の性別で絞り込み
- お気に入り相談員
- 相談履歴からもう一度相談
- 15分単位の延長
- 評価、通報、ブロック
- 相談員の受付開始通知
- アプリ内アカウント削除

安心して利用できる環境づくりのため、相談員による外部SNS・電話番号・メール・URL等への誘導を禁止し、検知・通報・運営確認の仕組みを設けています。

※KoiRelaは医療・心理療法・法律等の専門サービスを代替するものではありません。
